# LA News Telegram Bot

Автоматически публикует новости Лос-Анджелеса на русском языке в Telegram-канал.
Источники — RSS-ленты (LA Times, LAist, LA Daily News, NBC LA). Перевод и
переписывание текста — через Anthropic API (Claude). Публикация — через
Telegram Bot API. Запускается по расписанию через GitHub Actions, без сервера.

## Что нужно сделать один раз перед запуском

### 1. Создать новый Telegram-канал
- Создай канал в Telegram (например "LA News").
- Сделай его публичным и задай username (например `@la_news_channel`) —
  либо оставь приватным и узнай числовой `chat_id` через @userinfobot
  (перешли ему любой пост из канала).
- Добавь бота **@aipostbot** админом в этот канал с правом публикации сообщений.

### 2. Узнать TELEGRAM_CHAT_ID
- Если канал публичный — можно использовать сам username в формате `@la_news_channel`.
- Если приватный — нужен числовой ID вида `-1001234567890` (получить через @userinfobot).

### 3. Узнать TELEGRAM_BOT_TOKEN
- Напиши @BotFather в Telegram → `/mybots` → выбери @aipostbot → `API Token`.
- Скопируй токен (выглядит как `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

### 4. Получить ANTHROPIC_API_KEY
- console.anthropic.com → Create API key (обычный статичный ключ, не identity-based).
- Пополнить баланс (минимум обычно около $5 — на такой объём постов хватит очень надолго).

### 5. Указать ссылку на канал (для подписи в конце постов)
- Например `https://t.me/la_news_channel` (публичный) или инвайт-ссылка (приватный).

## Настройка репозитория на GitHub

1. Создай новый **приватный** репозиторий на github.com.
2. Залей туда все файлы из этой папки (bot.py, requirements.txt, .github/workflows/post.yml,
   state/seen.json, README.md) — сохраняя структуру папок как есть.
3. Зайди в **Settings → Secrets and variables → Actions → New repository secret**
   и добавь четыре секрета:

   | Имя секрета          | Значение                                          |
   |-----------------------|---------------------------------------------------|
   | `TELEGRAM_BOT_TOKEN`  | токен от @BotFather                               |
   | `TELEGRAM_CHAT_ID`    | `@la_news_channel` или числовой chat_id           |
   | `ANTHROPIC_API_KEY`   | ключ с console.anthropic.com                      |
   | `CHANNEL_URL`         | `https://t.me/la_news_channel` (или инвайт-ссылка)|

4. Перейди во вкладку **Actions** репозитория — GitHub может попросить подтвердить
   включение Actions для этого репозитория (кнопка "I understand my workflows, go ahead
   and enable them").

## Как проверить, что всё работает

1. Во вкладке **Actions** найди workflow **"LA News Autoposter"**.
2. Нажми **"Run workflow"** (кнопка справа, работает благодаря `workflow_dispatch`
   в файле post.yml) — это запустит бота вручную, не дожидаясь расписания.
3. Открой запуск, посмотри логи — там будет видно, сколько новостей найдено
   и что опубликовано (или почему что-то не сработало).
4. Проверь сам канал в Telegram — должны появиться 1-2 новых поста.

После этого бот будет запускаться сам каждые 30 минут (расписание в
`.github/workflows/post.yml`, строка `cron: "*/30 * * * *"`) — максимум
2 поста за один запуск (регулируется переменной `MAX_POSTS_PER_RUN`).

## Как добавить/убрать источники новостей

Открой `bot.py`, найди список `RSS_SOURCES` в начале файла — просто добавь
или убери словарь с `"name"` и `"url"`. Изменения подхватятся при следующем
запуске автоматически, ничего больше менять не нужно.

## Защита от повторов

Бот хранит в файле `state/seen.json`:
- ссылки на уже опубликованные новости,
- хэши заголовка+описания (чтобы поймать одну и ту же новость из разных
  источников, даже если ссылки отличаются).

GitHub Actions сам коммитит обновлённый `state/seen.json` обратно в
репозиторий после каждого запуска — это встроено в workflow, руками
трогать не нужно.

## Если что-то не публикуется

Смотри логи в вкладке Actions — там подробно пишется:
- сколько новостей найдено в каждой RSS-ленте,
- какие отфильтрованы как дубли,
- если Anthropic API или Telegram API вернули ошибку — текст ошибки
  выводится в лог.

Частые причины проблем:
- Бот не добавлен админом в канал (или не хватает права на публикацию) →
  ошибка от Telegram API в логах.
- Неверный `TELEGRAM_CHAT_ID` (например, забыли минус перед числовым ID) →
  "chat not found".
- Закончился баланс на Anthropic API → ошибка в логах при переводе, пост
  для этой новости пропускается, но бот не падает целиком.
